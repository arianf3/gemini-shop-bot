# 💎 ربات فروشگاهی اکانت‌های جمینای (Gemini Shop Bot)

یک ربات فروشگاهی حرفه‌ای، ماژولار و سبک (بدون وابستگی خارجی / Zero-Dependency) برای فروش انواع اکانت‌های Gemini Advanced، اکانت‌های اشتراکی، لایسنس‌ها و کلیدهای API گوگل.

---

## 🚀 ویژگی‌های کلیدی

### ۱. بخش کاربران (مشتری):
- 🛍 کاتالوگ شیک محصولات با تفکیک قیمت و وضعیت موجودی
- 💎 صفحه اختصاصی مشخصات، ویژگی‌ها و امکانات هر اکانت
- 🛒 صدور خودکار پیش‌فاکتور با کد پیگیری اختصاصی
- 💳 اطلاعات کارت به کارت و ارسال مستقیم فیش به پشتیبانی
- 📦 بخش «سفارشات من» برای پیگیری تاریخچه سفارش‌ها

### ۲. پنل مدیریت هوشمند ادمین (`/admin`):
- 🔐 امنیت کامل (دسترسی فقط برای ادمین‌های مجاز در `ADMIN_IDS`)
- ➕ **افزودن محصول جدید:** ویزارد گام‌به‌گام (نام ➔ قیمت ➔ تعداد موجودی ➔ توضیحات)
- ✏️ **تغییر قیمت آنی:** انتخاب محصول با دکمه شیشه‌ای و ارسال قیمت جدید به تومان
- 📦 **تغییر موجودی آنی:** افزایش یا کاهش موجودی یا صفر کردن (ناموجود) با یک پیام
- 🗑 **حذف محصول:** غیرفعال‌سازی سریع محصول از فروشگاه
- 📊 **آمار زنده:** تعداد کاربران و تعداد کل محصولات

---

## ⚙️ راه‌اندازی و اجرا

۱. قرار دادن توکن ربات تلگرام در `config.js` یا ارسال از طریق متغیر محیطی:
```bash
BOT_TOKEN="your_token_here" node bot.js
```

۲. مدیریت دیتابیس در مسیر `data/database.json` به صورت خودکار انجام می‌شود.
